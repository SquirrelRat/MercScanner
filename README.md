# MercScanner

A Path of Exile plugin for ExileCore that adds mercenary encounter tracking and UI overlays.
<img width="448" height="309" alt="image" src="https://github.com/user-attachments/assets/839db456-d749-48be-8ad7-952589cdd8c6" />

Displays colored stat rings on recruitable mercenaries based on their primary attributes (Strength, Dexterity, Intelligence, or hybrids). Supports tier rating (S/A/B/C/None) with per-mercenary assignment via a settings panel.

Shows HP and ES bars overhead, buff tracking, skill lists with attribute-colored names, and aura/cooldown timers. On hired mercenaries, shows a condensed action panel with the currently cast skill, cooldown timers, and aura uptime.

<img width="344" height="390" alt="image" src="https://github.com/user-attachments/assets/2ee7ac30-df60-47a7-9fc0-3733f148447b" />

Configurable distance filtering, per-stat colors, visibility toggles for each overlay type, an aura filter list, and custom tier colors.
